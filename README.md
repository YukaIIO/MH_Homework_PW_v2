# สมุดบันทึกงาน

## ฐานข้อมูลสำหรับใช้งานจริง

เว็บปัจจุบันใช้ IndexedDB เป็นโหมดออฟไลน์ในเครื่อง เพื่อให้เปิดใช้ได้ทันทีโดยไม่ต้องมีเซิร์ฟเวอร์ แต่สำหรับใช้งานข้ามมือถือ คอมพิวเตอร์ และแท็บเล็ต ให้ใช้ **Supabase** ซึ่งให้ PostgreSQL, ระบบ Auth และ Row Level Security ในบริการเดียว

1. สร้างโปรเจกต์ใน [Supabase](https://supabase.com)
2. เปิด SQL Editor แล้วรันเนื้อหาใน `supabase-schema.sql`
3. คัดลอก Project URL และ Publishable/anon key จาก Project Settings > API ไปใส่ใน `supabase-config.js`
4. เปิด Authentication > Providers > Email เพื่อเปิดใช้งานการเข้าสู่ระบบ
5. สำหรับระบบที่ปลอดภัยจริง ควรเพิ่มรหัสผ่านหรือ OTP ให้ผู้เรียน เพราะชื่อและเลขประจำตัวเพียงอย่างเดียวไม่ใช่ข้อมูลลับสำหรับยืนยันตัวตน

**ห้าม** ใส่ `service_role` key ลงใน `supabase-config.js` เพราะไฟล์นี้ถูกเปิดอ่านได้จากเบราว์เซอร์

## การออกแบบข้อมูล

- `profiles` เก็บชื่อและเลขประจำตัวนักเรียน
- `assignments` เก็บงานทั้งหมด โดยมี `user_id` เพื่อระบุเจ้าของ
- Row Level Security ทำให้ผู้ใช้เห็นหรือแก้ไขได้เฉพาะงานของตนเอง
